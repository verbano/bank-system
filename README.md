# Bank System

Микросервисная банковская система на Java с полным циклом финансовых операций.

## Технологии

- Java 22 
- Spring Boot
- PostgreSQL
- Kafka
- Docker

## Функции

- Управление пользователями и счетами
- Переводы с динамическими комиссиями
- Безопасное REST API
- Асинхронная обработка событий
- Ролевая модель доступа
